# Algorithms

Kotlin katas and algorithm practice — a training ground for language features and data structures.

Each kata is a small, self-contained exercise driven by tests: write the failing test first, make it pass, then simplify.

## What is here

- Kotlin language katas — delegated properties (by lazy, Delegates.observable, custom getValue/setValue), interface delegation, smart casts
- Classic data structures and algorithm exercises

## Running

    ./gradlew test

Kotlin · Gradle Kotlin DSL · JUnit
